# SIGNALWATCH Perception Datasets

This directory is reserved for real perception robustness assets.

Current state:

- No bundled frame sequences are checked in.
- The registry contains capture/import protocols only.
- Detection outputs, confidence values, continuity markers, and operational notes must be generated by browser-side inference at run time.

Asset-backed sequences may be added here only when the source frames are real captured or imported media with provenance notes.

Required sequence metadata:

- scenario label
- real source or capture route
- frame timestamps or capture timing notes
- degradation configuration
- reproducibility notes
- evidence packet schema version

Never add expected detections, expected confidence values, or fabricated continuity labels to dataset manifests.
